# Amazonie ve faktech

Přehledová aplikace do zeměpisu: 65 faktů a 22 příkladů z praxe o kácení deštných pralesů v brazilské Amazonii, seřazených do 10 témat, s vyhledáváním napříč celým přehledem. Stav k 22. 10. 2026, u každého údaje je odkaz na zdroj.

## Obsah

- `index.html` – celá aplikace v jednom souboru (data jsou přímo v něm, z internetu se načítají jen písma Google Fonts)
- `soupis-faktu-amazonie.pdf` – stejná fakta a příklady k tisku (5 stran A4)
- `.nojekyll` – urychlí zveřejnění na GitHub Pages (není nutný)

## Zveřejnění přes GitHub Pages

Aplikace běží na https://jandabenedikt.github.io/GMHS_role_play_Amazonie/ (na tuto adresu vedou i QR kódy v listech rolí).

**Aktualizace:** v repozitáři `GMHS_role_play_Amazonie` zvolte *Add file → Upload files*, přetáhněte soubory z této složky a potvrďte *Commit changes*. Stejně pojmenované soubory se přepíšou; web se obnoví do 1–2 minut.

**Nové zveřejnění jinde:** veřejný repozitář → nahrát soubory do kořene → *Settings → Pages* → větev `main`, složka `/ (root)` → *Save*.

## Ovládání

- U každého tématu lze přepnout zobrazení Vše / Fakta / Příklady z praxe; volba se pamatuje.
- Příklady jsou označené, zda jsou z Brazílie, nebo ze zahraničí.
- Šipky vlevo/vpravo přepínají témata, Esc vrací na přehled témat.
- Klávesa `/` skočí do vyhledávání; hledání nerozlišuje diakritiku.
